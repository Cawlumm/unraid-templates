# Lyftr templates for Unraid Community Applications

Templates for [Lyftr](https://github.com/Cawlumm/lyftr). Install `Lyftr-Backend` first, then `Lyftr`, and set its Backend address to `<unraid-ip>:<backend API port>`.

Issues: https://github.com/Cawlumm/lyftr/issues

Status: these templates are not yet listed in Community Applications and have not yet been installed on an Unraid server. Lyftr is in beta.
